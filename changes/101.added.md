`-instance NAME`: the scanner runs for one archive instance, production unless named, found among the life-weaver services on localhost:8321-8330 (one port per slot); it refuses to start when the instance is not serving, saying what it found. Its own address (8080+slot) and staging root (`~/.local/share/bytestone-scan-<instance>` for any instance but production) follow from the slot, so a scratch batch's masters never land in production's staging; `-archive`, `-addr` and `-staging` each override their part.
